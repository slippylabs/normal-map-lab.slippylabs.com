NORMAL MAP LAB

A flat sprite lit from one side stops looking flat. A normal map is just a picture where each pixel says which way that pixel faces, and you can build a convincing one out of the sprite you already have.

Normals

Unity, Unreal and most of the web want OpenGL-style normals, with green pointing up. Some tools (and older Unreal content) expect it the other way; if your lighting looks inside-out along one axis only, this is the switch.
